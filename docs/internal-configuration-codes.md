# 内部配置编码免填写

## 行为

- 新增配置时，前端自动生成内部编码，编码输入框不再显示。
- 列表与相关下拉选项优先显示名称，不再拼接内部编码。
- 编码仍随原有接口提交，内部关联和后端字段不变。
- 编辑已有记录时保留原编码；保存失败重试不会重新生成编码。
- 新增另一条记录时会生成新编码。使用随机字节，不使用可修改的名称生成编码。

## 覆盖范围

坐席、AI 助手、模型与语音服务商、知识库与 FAQ、意图及分类、AI 编排、
自动外呼任务、工作时间、队列、表单模板及字段、FreeSWITCH 节点与节点组、
线路、ACL、IVR、开放接口应用、拨号策略、质检模板及评分项、抽检计划、
技能组、紧急程度、语音信箱、工作流定义和岗位内部编码。

FAQ 合并改为按名称选择已有 FAQ。同一评分维度下的新评分项共享维度编码。
FreeSWITCH 节点的对接配置仍保留必要的编码输出，供 media-agent 等程序使用。

## 不随机替换的内容

分机号码和鉴权账号、运营商短信模板 ID、区号和国家码、语言标识、
呼入端口与账号标识、业务单据编号、部门及岗位类别、字典和权限配置等有业务意义的值。
模型名称仍填写服务商实际提供的模型名称；仅模型内部编码自动生成。
